Area inicial de frontend do MVP do IncluJus AI.

Stack-alvo:

- Next.js
- TypeScript
- Tailwind CSS

Esta pasta serve, neste momento, como limite de implementacao para:

- fluxo de envio e submissao;
- visualizacao dos resultados de acessibilidade;
- fluxo de revisao humana;
- futuras telas de relatorio e administracao.
